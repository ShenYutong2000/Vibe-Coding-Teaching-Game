# Little Makers · Vibe Coding Studio

A Vibe Coding education MVP for children around age 10. Kids start with a game idea and move through a design map, mission confirmation, prediction, playtesting, and debugging to complete one creative loop.

## Run the prototype

```powershell
cd app
npm install
npm run dev
```

Create a production build:

```powershell
npm run build
```

This version uses a space-cat sample, scripted AI guidance, and a playable mini-game. Accounts and cloud saves are not connected yet. See [docs/day1-flow.md](docs/day1-flow.md) for the flow notes.
